Strongevity Booking App

A private, personal tool that keeps one person's regular Strongevity fitness classes booked at Shine Strong Fitness. It is not offered to the public and is used by a single household.

What it does

  • Checks the gym's class schedule a few times a week and books the person's regular class times, or joins the waitlist when a class is full.
  • Adds booked classes to that person's own Google Calendar.
  • Sends a short status email to the household after each check.
  • Reads the gym's "off the waitlist" emails in that person's Gmail so the calendar stays up to date.

Google data

The app uses Google sign-in only for the account owner's own Calendar (to add class events) and Gmail (to read the gym's waitlist emails and send status emails). See the privacy policy.
