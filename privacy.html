Privacy Policy

Strongevity Booking App. Last updated October 25, 2026.

The Strongevity Booking App is a private tool run by one household for its own use. It is not offered to the public.

Google data the app accesses

  • Google Calendar (calendar.events): to create events for booked fitness classes and to check for an existing event at the same time so duplicates aren't created.
  • Gmail read (gmail.readonly): to find and read emails from the gym's booking system (for example "Off the Waitlist") to learn which class was booked. Other emails are not read.
  • Gmail send (gmail.send): to send a short status email about class bookings to the household.

How the data is used and stored

  • Data is used only to book classes, keep the calendar current and send status emails. It is not used for advertising, profiling or any other purpose.
  • The app stores only a sign-in token and a small record of class dates and booking status, on a computer owned by the household.
  • No Google data is sold, shared with or transferred to anyone else.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Stored records are deleted on request.
